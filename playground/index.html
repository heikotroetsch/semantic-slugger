Turn any title into a short ID

Type a title in German or English. You get an ID that people can read, say on a call and remember.

    How it works

    1. Clean up. Lower case, umlauts to ae/oe/ue, emojis and punctuation out.
    2. Find the important words. Stop words go. German compounds are split. Rare words, names, years and versions rank high.
    3. Shorten. Words are cut at natural points, so they stay readable: sourdough → sourd.
    4. Make it unique. With a database, a taken ID first gets other words that tell the titles apart. Only then a short code is added.

    Same title and same settings always give the same ID. On this page there is no database, so every title is checked on its own.

    Use it in your code

    npm install semantic-slugger
    import { slug } from 'semantic-slugger'

slug('How to Bake Sourdough Bread at Home')
// → 'bake-sourd-bread'

    Zero dependencies. Works in Node and in the browser. Adapters for an in-memory store, SQL and Prisma keep IDs unique. Read the README.
